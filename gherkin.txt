Feature: Seminar and Talk Tracker

  I want to track seminars and talks I've attended
  So that I can maintain a learning record and export it for reporting

  # STORY 1: INPUT TALK DETAILS (Flask-WTF Forms + HTMX)
  # ============================================================
  
  Scenario: Add a new seminar with HTMX modal form
    When I click the "Add New Seminar" button (#add-seminar-btn)
    # HTMX: hx-get="/seminar/create/" triggers modal via hx-target="#modal-container"
    Then a modal dialog should appear with the seminar form
    # Flask-WTF: SeminarForm with FlaskForm, using CSRF protection
    And the form should have CSRF token {{ form.csrf_token }}
    And the form should have fields: date, topic, speaker, hours, organizer, notes
    # Field validation: DateField, DecimalField with validators
    When I fill in:
      | Field     | Value                                    |
      | date      | 2026-05-15                              |
      | topic     | Introduction to Machine Learning        |
      | speaker   | Dr. Sarah Chen                         |
      | hours     | 3.0                                     |
      | organizer | Data Science Institute                  |
      | notes     | Covered supervised learning basics     |
    And I click "Save Seminar" 
    # HTMX: hx-post="/seminar/create/" with hx-target="#seminar-list" hx-swap="afterbegin"
    Then I should receive a 200 OK response with HTML partial
    And the new seminar should appear at the top of the list
    And the modal should close automatically
    # HTMX: hx-trigger="closeModal" event dispatched
    And I should see a toast notification: "Seminar saved successfully!"
    # Flask: flash('Seminar saved successfully!', 'success') with HTMX OOB swap

  Scenario: Add seminar with inline validation (Flask-WTF errors)
    When I click "Add New Seminar"
    And I submit the form with empty topic field
    # HTMX: hx-post with validation errors returned as HTML partial
    Then I should see field-specific errors rendered next to each invalid field
    # Flask-WTF: form.topic.errors rendered in template
    And the error should say "This field is required"
    And the modal should remain open with form data preserved
    And no database INSERT operation should occur
    # Flask: View checks if form.validate_on_submit() before saving

  Scenario: Successfully create seminar via SQLAlchemy ORM
    When I submit valid seminar data via HTMX POST request
    Then Flask view should call db.session.add(seminar)
    # Model: Seminar Model with relationship to User
    And the seminar should have user_id = current_user.id assigned
    And the created_at timestamp should be auto-set via default=datetime.utcnow
    And a success response with status 200 and HX-Trigger header should return
    # HTMX: Response includes HX-Trigger: {"seminarAdded": true}
